Attack Type Reference
Prompt Injection

Tests if the LLM can be manipulated to ignore system instructions via carefully crafted user inputs using word-level substitution and semantic steering.

PII Exfiltration

Attempts to extract personally identifiable information (email, phone, SSN) via few-shot learning and prompt chaining techniques.

Jailbreak Attack

Multi-turn attack attempting to bypass LLM safety guardrails by iteratively escalating adversarial prompts across multiple conversation turns.

Hallucination

Detects hallucination vulnerabilities by probing for fabricated package names, fake citations, or non-existent information generation.
